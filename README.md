# Masahim Uddin — Personal Portfolio Website

A modern, dark-themed, professional developer portfolio website for **Masahim Uddin** (Python Developer).

## 🚀 Live Demo
- **URL**: [https://MASAHIM-UDDIN.github.io](https://MASAHIM-UDDIN.github.io)
- **GitHub**: [https://github.com/MASAHIM-UDDIN](https://github.com/MASAHIM-UDDIN)

## 🛠️ Built With
- **HTML5**: Semantic tags, accessible ARIA roles & SEO structure
- **CSS3**: CSS Custom Variables, Flexbox, CSS Grid, Ambient Glows, Glassmorphism, Responsive design
- **JavaScript (ES6+)**: Scroll reveals (`IntersectionObserver`), sticky navbar, mobile drawer menu, cursor light tracking

## 📁 Repository Structure
```
├── index.html        # Main homepage HTML
├── css/
│   └── main.css      # Design tokens, responsive grid, animations & theme
└── js/
    └── app.js        # UI interactions, scroll reveal & contact email handler
└── README.md         # Project documentation
```

## 💻 Local Setup
To run the portfolio locally:
```bash
# Serve locally using Python or Node
python -m http.server 8000
# or
npx http-server . -p 8000
```
Then open `http://localhost:8000` in your web browser.
